SALES PERFORMANCE
ANALYSIS

This project analyzes Q4 sales performance and evaluates the impact of a strategic turnaround initiative at SALIENT Ventures using advanced Microsoft Excel analytics. HR ATTRITION
ANALYSIS

This project used Microsoft Excel dashboard to analyse employee attrition through key workforce metrics, including overall attrition rate, turnover distribution across departments and job roles, and attrition patterns by salary bands and demographic groups. By quantifying retention risks and identifying high-attrition segments, the analysis highlights critical trends such as departments or roles with above-average turnover and correlations between compensation levels and employee exit rates. These insights support data-driven HR decision-making, enabling targeted retention strategies, improved workforce planning, and more effective allocation of resources to reduce turnover and enhance organisational performance.

Retail Data
Integration

This project focuses on automating retail sales reporting for PureSip Beverages using Microsoft Excel and Power BI. By leveraging local folder connectivity, multiple retailer spreadsheets were consolidated into a centralized and automated data pipeline, eliminating the need for manual data aggregation. The transformed dataset was used to build interactive Power BI dashboards that improved visibility into sales performance across retailers, products, and time periods. This solution enhanced data accuracy, reduced reporting delays, and streamlined the overall sales analysis process, enabling more efficient and data-driven decision-making for business stakeholders.
